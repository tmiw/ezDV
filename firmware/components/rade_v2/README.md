# rade_v2

RADE V2's receiver and transmitter for the ESP32-S3, from
[rade_c](https://github.com/freedv/rade_c) at commit
`c8a3dc156045cae2cd251e1a4be0c304c9ddf2f9` (BSD 2-Clause, see `LICENSE`).
Changes are kept here rather than upstream.

Changed from rade_c:

- `rade_rx_v2.c/.h`: `rade_rx_v2_demod()` and `rade_rx_v2_decode()` split
  `rade_rx_v2_process()` in two, so the decoder can run on the other core.
  The output is bit-identical to `rade_rx_v2_process()`.
- `rade_bpf.c/.h`: the band-pass filter is one complex FIR with separate real
  and imaginary history, so a real input costs two real dot products per
  sample.
- `rade_dec_v2.c/.h`: the decoder's layer buffer (3.7 KB) is in the state
  instead of on the stack.

New:

- `q8_layers.c`: generated by `tools/rade_models` (do not edit). The int8
  layer tables for `firmware/models/q8_models.bin`.
- `rade_models.c/.h`: loads the "models" flash partition into PSRAM and binds
  the tables to it.

The other files are unchanged from rade_c.
